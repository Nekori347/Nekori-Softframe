## 给执行 AI

- 从文字中取得结构契约，HTML用于阅读布局与交互方法。
- 后续移植只修改实际任务相关组件，不把教学目录、提示和案例状态文案塞进产品。
- 单文件可本地打开；源片段未打包第三方字体或图标库。历史代码的缺口见上表，不自动扩展成当前开发任务。
- 历史CSS参数、风险阈值与图形近似不升级为固定官方规范。
