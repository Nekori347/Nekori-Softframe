## 使用约定

1. 意图与功能归属先于布局和装饰；新功能不自动产生新页面、按钮或导航。
2. 左栏、顶部标签、分支节点是形式；语义层级由具体项目决定。
3. 正文规范是当前规则；案例是独立重建参考，像素参数不自动成为固定标准。
4. 试验参数、备选资源、未验证能力保持其原状态。
5. 普通控件保留已确定圆角；几何分区、直角装饰与主体圆角各有职责。

## 归档范围
