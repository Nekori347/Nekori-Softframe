# 组件、线条与参数控件

依据001–004、008–010；滑条以004最终纠正为准，所有尺寸受内容完整性约束。

本文件已合并历次有效修正，是当前组件规则入口；后文含开口精调、扁平胶囊、紧凑仪表端点、透明失效元按钮和容器节点的详细结构。

## 选择与层级线条

| 类型 | 结构和语义 |
| --- | --- |
| 身份线 | 顶部内缩的独立强调条，Logo/程序名与窗口控件置于其下方；不再使用标题栏中央1px细线替代身份条。具体组合见窗口规则 |
| CategoryItem | 名称前短竖选中线→可选识别图标→名称；可轻背景/文字权重，不重复堆状态符号 |
| ConnectedTab/WorkspaceTab | 圆角耳朵内、文字上方短选中线；底边与内容连成同一表面，不加横线截断，不误作下划线 |
| Section | 主题竖线＋标题＋延伸长线＋克制末端技术标记 |
| Accordion | 名称＋中性细引导线＋折角/短展开符号，不套完整按钮卡片 |
| Branch | 缩进＋竖线＋L连接，表示父子 |
| Item | 可选小图标/标签＋名称＋选中标识 |

顶部身份条与标签内部短线职责不同。结构线低对比中性，选中线主题色；只强调当前节点与直接相关段，不染整棵树。折线用干净L形/一次转折，不闪电折返。普通分支图标可省略。展开连接线随内容延伸，符号同步换向。

## 按钮和列表

| 类型 | 表达 |
| --- | --- |
| Text/Ghost | 无常驻容器或Hover才显，低强调 |
| Soft | 圆角弱填色，普通设置/工具 |
| Outline | 圆角细轮廓透明底，次级/非当前 |
| Segmented | 共用暗轨道，扁平亮选择块短距离滑移；仅整体外轮廓轻阴影，尺寸不跳动，选项完整 |
| Primary/Signal | 明确主题表面＋短文案，少数主要动作 |
| MetaAction | 内按钮＋有空隙独立外圈，同一点击区 |

普通工具按钮可小型图标、Hover显容器。主要执行与删除、同步、发送等明确后果动作保留准确文案。危险色独立。选中选项可主题线＋轻背景＋字重。

高强调主要动作可采用标识→文案→方向双箭头→端点菱形，仅少数最高强调动作，不每个保存都添加。MetaAction用于全局/批量/系统级意义，不要求所有重置或危险操作都双圈；外圈与内层可不同透明度、分阶段响应，但不能分成两个独立按钮。

列表连续整体表面，非每行独立大卡片。结构：选中线→图标→主名称→次信息→右状态/操作。数据表紧凑，设置可更高，信息卡可更多辅助内容。Hover、Selected、Focus分开，Hover不冒充选中。

普通选择：局部主题线＋轻背景；高权重对象：独立轮廓＋局部角标＋主题边缘。不要整卡染黄，不给普通卡片全加发光边。

## 滑条统一母型

**圆角细线轨道＋横向短胶囊操控柄＋独立读数。** 轨道不是槽，柄不是圆点；柄压在线上，不能埋入厚槽。轨道低明度，柄白色/高明度；通常右侧等宽读数。Active Range如需要仅细线强化，默认不大面积填充。Focus细轮廓/轻亮，Disabled整体降强调但结构可辨。

| 滑条类型 | 数值/轨道行为 | 精调 |
| --- | --- | --- |
| 连续 | 连续线＋胶囊柄＋读数 | 按实际精度需求 |
| 连续＋步进器 | 拖动粗调；右侧输入/增减一体 | 同一状态同步 |
| 数值步进离散A | 外观连续，按固定步长吸附；可无刻度或弱微刻度 | 需要时可有 |
| 预设轨道分段B | 线轨道关键刻度/短线/锚点，柄吸附；下方标签表达档位 | 无需输入/上下微调 |

A用于数值多、无需无限拖动精度，步长1/5/0.1/0.05是示例；不要画全量密集刻度成算盘。B用于低/中/高/极高、比例预设等枚举；分段仍是线，不能退回长胶囊槽＋圆点。

独立NumericStepper继续存在：尺寸、间距、偏移、次数、阈值等不需轨道时，只用可编辑数值＋同容器增减。不能为了好看强加滑条。

一体步进器共享数值、单位、增减、焦点和状态；视觉采用低强调左右开口括号臂，不闭合成小矩形、不铺底。可只显示一段可编辑数字，在Hover/Focus时才强化轮廓；不必显著输入框，也不画内部重复框。禁止输入框旁外挂上下按钮。拖动、输入、微调同步更新，支持明确范围和键盘数值语义。

## 方向符号

数值增减用小三角/短折线；展开折叠用Chevron/小三角/折角；水平微调用短左右折线；树连接用L/分叉。真正前进返回可方向箭头，排序可三角组合。正式图标优先统一SVG描边/尺寸/对齐，不用大量大号↑↓←→作为所有控制。折叠表示状态，不像“向下移动区域”。

## 数值状态与进度

| 组件 | 意义 | 表现 |
| --- | --- | --- |
| Slider | 输入目标值 | 拖动短胶囊柄 |
| Capacity/Utilization | 占用/负载 | 紧凑短横＋半方框端点、连续填充、内部明暗短刻线、按指标语义映射状态色与文字 |
| Progress | 已完成任务比例 | 完成段实线、未完成段工业斜纹、短端点刻线，同一轨道推进 |
| StepProgress | 当前步骤 | 节点、连接、完成状态 |
| Indeterminate | 在运行但未知比例 | 受控短段运动，不伪造百分比 |

容量表达正常/临界/超限，危险色不能由当前平台主题色代替。Slider和Progress不能只用disabled切换语义。进度图的斜纹等待区不可误套成滑条粗填充槽。

## 图标容器层级

G0信息：小弱色无背景；G1普通：单层轮廓，Hover底；G2功能组：独立轻容器/分隔；G3强调或当前：高对比底、反色/填充；G4元操作：独立双轮廓与间隙。它们是本套归纳，非游戏官方分类。

普通Outline、分类Outline/Filled、重要选中优先Filled；元级仍可普通图标＋独立容器。工业标记、折线、刻度自行几何绘制，不为几个符号再装图标库。品牌Logo独立且不任意染色改形。选型见[资源](04-资源与参数.md)，对应案例见[文字与HTML案例](06-案例索引.md)。

元级失效态为独立的透明无背景单圈线框，无地形、阴影或第二外圈；普通按钮禁用减强调规则不能覆盖此特例。容器型分类/文件夹条主题线置于内边距内，数量与折叠尾置；可选logo/拖动柄、名称续行及标签排序规则见07。


## 一体化精调器：开口括号、数字主导

结构为`左括号臂 → 可编辑数值 → 可选单位 → 附着的上下微调区 → 右括号臂`。左右各短竖线带极短上下横臂，中部开敞，不能闭合成矩形。共享操作单元、状态与焦点，不等于必须共享一块显眼底板。

与滑条裸读数使用同一字号、字重、对齐逻辑和数字风格。上下SVG折线小而弱，无独立按钮外框、胶囊或高亮底色；可用更大的透明命中区，但不能挡住输入、单位或相邻操作。整体低于条目外框的存在感。用户已接受此开口形态。

输入必须真实可编辑，不能以span冒充输入。装饰括号可aria-hidden，真实增减按钮及数值输入不能被隐藏。键盘、范围、失焦提交和与滑条同步要求继续有效。

## 胶囊：扁平内核，轻外阴影

普通下拉、分段与胶囊按钮以纯色和明度区分状态。整体外轮廓可有轻柔投影；不能所有区域叠高光、内阴影、凹凸边或给选中块强烈悬浮感。尺寸适应完整文字与图标。

新增图标＋文字胶囊：`前置图标 → 短名称`同属一个胶囊。未选中中性线框/低强调，选中浅色实体；它属于分类/导航或选择语义，不能自动套元操作双轮廓。品牌标识仍保留本来形态与颜色规则。

## 容量条：连续条体，独立仪表标记

结构从左到右为`紧凑左限位符 → 连续暗轨与连续信号填充 → 镜像右限位符`。刻度独立绘制：落在填充内为暗短线，未填充内为亮短线；高度小于条体，上下留微距，不能割穿整条。

端点左形可用文字示意`-┌ / -└`理解，但正式应画SVG或几何线：两条上下平行极短横线，在其右方紧邻一个向轨道开口的半方框。括号横臂也极短，横线与半方框之间、括号与条体之间仅微小间隙。整体比条体略高且垂直居中。不是E字、不是三件松散装饰。右端镜像。缩放时保持符号自身比例，不将整个宽SVG非等比拉伸而拉长短横。

参考安全绿为`#B4D744`，替代早期容量示例的`#A0BA54`。颜色由**指标风险语义**驱动：负载高可能危险；剩余电量低可能危险。区分显示百分比与风险值，再映射绿/黄/橙/红，同时提供文字。阈值、方向、其他色值由具体指标决定；历史演示区间不固化。不能把所有指标高值一律染红。

## 元级胶囊：有效与失效为独立结构

有效态：实体胶囊＋分离外轮廓与微间隙；可含辅助短线、文字、右圆形符号，以及仅右侧低对比共享地形片段。普通按钮不全部双圈。

失效/暂无修改：**透明无背景**、单层弱线框、弱文字与图标。无等高线、阴影、额外第二圈、高光。背景随所在表面透出，不能硬设黑色。与一般按钮的禁用规范区分，禁止只给有效态整体降透明度。

恢复符号采用更接近对称的几何分段环，不用refresh/rotate类带箭头循环符号；完成符号短而有力度，避免纤细勾。几何近似不能冒称官方原图标。数字微调等方向控制仍沿用统一SVG折线。

## 分类、文件夹与折叠容器条

排列为`内边距 → 内置主题细竖线 → 可选点状拖动柄 → 可选logo → 名称 → 可选数量 → 尾部折线折叠按钮 → 内边距`。主题线是内容序列的一部分，与外框留边，不贴外边界；视状态增强，不多添不明蓝框。

名称独占弹性列，多行续行对齐名称起始线。可选元素不存在时不留空槽；子节点用有限缩进、中性连接或较弱线表达层级，不递归叠大卡片，不让换行前方出现过大留白。圆角、字号、间距沿用主体系统。

折叠符号尾置、统一几何Chevron，数量在其前；纯展示分组可省略折叠。排序时点柄增强、内置主题线可反馈，插入位置用清楚的细主题线，不靠整条大面积高亮或发光。真实可排序才显示相应可操作暗示，并提供键盘/替代排序入口；仅演示排序外观时明确标注。

## 耳朵标签的图标与排序

名称前可选图标。选中短线保持在耳朵内部文字上方，标签与内容连面。可拖排序时**上方装饰短线本身**是拖动提示与反馈区；可扩展透明命中范围，不额外塞点状拖动柄挤占标签内容。不可排序标签不显示抓取暗示。实际排序、选择、焦点和内容面板对应关系应保持同步；只切样式不等于完整Tab。

## 检查顺序

1. 精调是否低存在感开口括号，数字仍可编辑？
2. 胶囊是否扁平，仅外轮廓轻阴影？
3. 仪表端点是否紧凑、微高、居中，刻度是否内嵌且不割穿？
4. 状态颜色是否由指标语义决定，可支持反向映射？
5. 失效元按钮是否透明、单圈、无纹理阴影？
6. 节点主题线是否内置，名称续行是否对齐，数量和折叠是否尾置？
7. 图标胶囊、带图标耳朵和顶部短线排序反馈是否按语义使用？
