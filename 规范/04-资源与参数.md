# 字体、图标、动效及试验参数

## 默认资源组合

采用批次008：**Sarasa UI SC＋Rajdhani＋JetBrains Mono＋Tabler Icons**。

| 角色 | 选择 |
| --- | --- |
| 中文菜单、列表、输入、设置正文 | Sarasa UI SC |
| 中文普通标题 | Sarasa UI SC SemiBold |
| 工业英文短标题 | Rajdhani SemiBold/Bold |
| 技术编号、时间、版本、坐标 | JetBrains Mono |
| 大英文水印 | Rajdhani Bold、低对比、少量空白区 |
| 设备式大数字 | Rajdhani或JetBrains Mono，按对齐精度 |
| 主图标 | Tabler Outline/Filled，经统一语义包装 |

数字仅在稳定位置/列对齐/技术身份需要时使用Mono或tabular-nums，可关闭不必要连字。中文不能为窄英文字体牺牲空间。字体按角色/组件作用域应用，不全局覆盖宿主字体变量。子集或回退应保留中英文、标点、繁体覆盖。

备选B：Source Han Sans SC＋Oxanium＋JetBrains Mono，工业强化；C：IBM Plex Sans SC＋IBM Plex Sans Condensed＋IBM Plex Mono，专业工程。Fluent可替代主图标以偏原生柔和，既有Lucide无问题不强制迁移。Iconoir/Carbon为其他候选，不全量混装；同语义图标及同层级描边/重心/留白稳定。

Oxanium仅少量展示，不铺正文；Smiley Sans仅特殊中文展示实验；Bender/Morro授权在原研究中仍待核实。历史许可判断和Remix许可变更说法留在批次008，不当作本轮新核实的发布许可。尚未打包任何字体/图标。

## 字体和信息层级

主标题较大较重；章节标题中等半粗＋竖主题线；正文中性舒适行高；控件文字清晰紧凑；技术注记小号弱色等宽。`//`限高层/模块/特殊状态，不每个按钮前添加。水印不覆盖普通数据列表或编辑区。

## 连续性与动效

1. 视觉：章节→左参数名→右值→调整入口，基线/内边距/操作位置稳定。
2. 形态：耳朵与内容连面、分类线与项相连、进度共轨、节点连子项。
3. 交互：Tab选择线沿位置过渡；Accordion符号和线随展开；分段块沿共享轨道；滑块与值同步；页面离入场方向协调。
4. 反馈：Hover轻底/边，Press短压低/明度，Selected稳定保留，Expand随内容延伸，Completed明确稳定，高影响动作清楚后果与状态。
5. 时间：统一Motion参数，不每组件各自速度。拖拽实时跟手，不能以缓动增加操作延迟。

动效说明前后状态，不强制每控件动画。克制不等于察觉不到。避免弹跳、大片扫光、长入场、无限闪烁、持续流动HUD；减少动态模式保留准确状态并移除不必要运动。借鉴游戏节奏，不复制开场或3D镜头。

## 仍属试验范围

以下来自历史建议，尚未被像素样板标定，不得作为已验收固定规格。

| 参数 | 建议起点 |
| --- | --- |
| 主体圆角 | 8–18px，按角色分级 |
| 胶囊 | 半高或Pill |
| 工业装饰角 | 0px，独立于主体 |
| 普通结构线 | 1px低对比 |
| 选中线 | 2–4px按语义 |
| MetaAction | 外线1px，内外间隙约3–4px |
| 排线 | 周期约5–9px、低透明度 |
| 点阵 | 点距约4–8px、方向渐变 |
| 滑轨 | 2–4px，但视觉必须是线而非槽 |
| 地形 | 初试12–24高程级，每4–5级主线；按素材尺寸调整 |
| 主题地形母版 | 约2–4份，按用途而非组件独立生成 |
| 标题/外围色层不透明度 | 55%–80% |
| 常驻侧栏不透明度 | 72%–90% |
| 主业务底板不透明度 | 88%–100% |
| 卡片/设置行不透明度 | 92%–100% |
| 密集文字/编辑不透明度 | 96%–100% |
| Hover/Press | 90–150ms |
| 选中线 | 150–220ms |
| 按钮/分段 | 140–220ms |
| 折叠 | 180–260ms |
| 抽屉/大面板 | 220–320ms |
| 数值填充/进度状态 | 250–450ms |

不透明度不是透明度；这些区间不是Apple/Microsoft/游戏官方规定。字体实际字号、密度、对比、最终描边和纹理强度仍需在具体案例标定。Tabler原绘制网格/描边也不等于每处最终像素尺寸。

## 集中配置，保持轻量

Color/Surface、Material、Shape、Line、Typography、Icon、Component States、Motion、i18n、Theme Identity，加上Texture、TexturePlacement、Decoration Density/Outline Hierarchy。它们是集中改值的职责，不要求皮肤编辑器或数据库。Hover/Selected/Focus/Disabled/Loading分别定义，固定文案集中多语言管理。
