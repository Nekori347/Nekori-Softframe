# 窗口表现与表面层级

把已确认的材料分配、身份线、信息归属与命令规则放进完整窗口。布局形式不规定导航的语义层级。独立打开[窗口与层级案例](../案例/窗口与层级.html)，无需内部组件图或PNG。该页是通用教学场景，不是某个真实产品的导航规划。

## 从外到内的职责

| 表面 | 构成与关系 | 案例表现 |
| --- | --- | --- |
| 桌面环境 | 窗口外部空间，提供环境色参照 | 独立底景，窗口投影与其分离 |
| 系统外壳 | 柔和连续圆角、原生或后备材料 | 云母模式为不透明环境染色；亚克力模式为受控半透明外壳 |
| 标题栏 | 独立顶部强调条、Logo、程序名、窗口控制 | 与外壳连续，不塞业务参数 |
| 常驻导航 | 功能归属与当前位置 | 较轻半透明导航面、内部主题线；在另一形式中可承接当前工作区的次级分类 |
| 业务底板 | 稳定可读的内容承载 | Paper/Ink Base，不透桌面图案 |
| 内容面 | 工作区标签与内容连面，分组有秩序 | Raised；工业纹理限局部设置/资源行 |
| 嵌入属性组 | 内容内部的次级分组 | Recessed，低装饰、无额外模糊 |
| 常驻详情面 | 当前对象的辅助信息 | 独立Raised侧面板，可关闭；窄处转为下方排列 |
| 菜单 | 当前上下文的短时命令 | 锚定更多按钮，局部Acrylic模拟与实色后备 |
| 独立详情浮层 | 临时查看对象细节，非模态 | Elevated，较高阴影、稳定底色，不加多层模糊 |
| 模态遮罩 | 隔离当前Owner下的内容 | 暗化所属窗口范围，不给桌面整幅染黑 |
| 确认表面 | 明确提交与退出，阻止模态穿透 | 相对Owner居中，取消左、保存右，安全初始焦点 |

这些是语义关系，不要求每一行对应一个全屏容器或独立软件包。层级更高不机械等于颜色更亮，使用边界、投影、尺寸和交互关系共同表达。独立菜单和模态仅在需要时存在。

## 外壳与正文不是同一种表面

Mica模式为不透明环境染色底层；Acrylic模式为受控半透明外壳，两者分别演示，不能把Mica解释成透视桌面的玻璃。标题栏与外壳连续；导航以色层/透明程度区分；正文、表格、编辑面保持稳定纸墨底色。HTML仅模拟，真实Mica/Acrylic须宿主实现。

不反复给导航、卡片、子卡片、输入框各加模糊。亚克力形式在外壳一次模糊，菜单是按需独立的临时表面；内容卡片通过纸墨色阶分层。云母形式不以CSS透明模糊冒充原生材料。切换“不透明后备”同时移除外壳和菜单模糊，保持层级、文字和功能。Paper/Ink主题各有完整色阶，不简单整体反相。

窗口控制属于标题栏。在HTML中，最小化将示例工作区收起、最大化扩展预览窗口、关闭隐藏该示例并给出重开入口；这些是浏览器内状态，不调用系统窗口API。

## 业务与辅助表面的布局

常见工作区阅读顺序为标题/当前视图 → 内容标签 → 分组标题 → 左对象/参数 → 右值与操作。当前对象辅助信息放在详情面板。菜单命令属于当前视图，不因为新增一项就创建顶层导航。

耳朵标签与内容底板连续，身份长线与标签内部短线不能混用。内部控件的细节在[组件案例](../案例/index.html)；窗口案例只取少量控件说明层级，不重复整套组件库。

窄窗口优先调整外部布局：导航转紧凑横排、详情转下方、控件必要时换行。不能靠压缩文字、裁数值、把所有表面改透明来解决空间不足。教学页的“较窄窗口”用于演示布局；实际窗口尺寸仍需由宿主控制。

## 浮层的定位、焦点与反馈

- 菜单跟随触发按钮定位；边界留距，关闭后可回到触发处。Esc退出，方向键切项。
- 独立详情浮层有自己的关闭入口，关闭回到触发处；它不阻塞全部工作区，不冒充模态。
- 确认框以Owner窗口矩形为定位依据；空间不足时留在可见视口内。随窗口尺寸变化重新定位。
- 本例采用浏览器原生dialog维护模态焦点与背景交互隔离，并另外在Owner范围内绘制遮罩。浏览器顶层模态会暂时阻止参考页其他控件，不能据此声称实现多个系统窗口的Owner行为。
- 取消不提交，保存只更新演示状态；成功用局部状态反馈，不再弹成功确认框。

## 参考标注与产品界面分开

“标注层级”开关、材料图例、透明后备和主题预览放在示例窗口外。开启标注可看到表面边界，关闭后窗口内部保持正常任务语义。移植业务界面时删除参考控制、教学说明和虚构状态。

背景网格、等高线与点阵仅使用D0/D1级；主内容行复用与组件参考同源的高度场母版。标题栏和窗口大外壳不铺满地形，模态正文不加纹理。没有必要用大量HUD、开场动画或霓虹表达高层级。

## 标题身份构成：由已完成项目校正

对照Bili-MonitariNYA的实际源码，顶部身份强调条独立于标题栏：3px高、上方3px与左右10px内缩、圆角；下方标题栏紧凑，Logo与程序名组成同组，操作区在尾部。该项目Logo悬停会让布局腾出空间，强调条也随之避让，而不是让图片覆盖程序标题。

本例采用3px顶部条与自绘几何Logo、Atlas程序名/副标题，避免以1px居中细线替代身份条。3px和内缩值是来源实例/本例参考，不能无条件冻结到所有窗口。Logo不必胶囊底框；真实产品沿用自身品牌。此案例不复制对方Logo或粉色，不引入其彩蛋行为。

## 导航层级由信息架构确定

常见形式为左侧竖列承载一级、顶部耳朵承载二级、节点分支承载三级。但这些只是可能的角色映射，不能根据位置就判定级别。

- 侧栏为一级：适合以全局功能/分类为主要切换单位的工具。顶部标签只切换当前功能下的视图。
- 顶部工作区为一级：适合画师工作台、多文档或浏览器式项目切换；左侧分类属于当前工作区，内部耳朵又可承载视图。节点条承担更局部的组织。
- 产品可按对象、任务、频率选择其他组合；不为凑齐三级而新增空层级。功能归属仍先于布局。

本例在窗口外提供两种形式切换，复用同一份演示内容，重点展示角色关系，非实现两个完整业务产品。实际项目应先确定工作区和对象边界，再决定哪些位置承载导航。

## 与主组件案例的对应

| 窗口中的角色 | 主案例规则 | 本例执行 |
| --- | --- | --- |
| 标题栏、更多、关闭详情 | G1 / IconToolButton | 无常驻重容器，几何图标与完整命中区 |
| 详情、检查等次级动作 | Soft | 中性弱表面，不和保存争主强调 |
| 保存 | Primary/Signal | 少量主要动作使用主题色；不是元级双圈 |
| 当前分类 | CategoryItem | 内容内部竖线、名称、当前状态 |
| 内容耳朵与主工作区耳朵 | ConnectedTab | 短线在内部上方，选中耳朵与对应表面连面 |
| 进阶预览参数 | C10容器节点 | 内边距内主题线、可选图标、名称、数量、尾端折线 |
| 质量选择 | 普通胶囊下拉 | 扁平内核，整体轻外阴影 |
| 不透明度 | 连续Slider | 线轨道＋短胶囊＋读数，不新增闭合精调 |
| 确认命令区 | DialogActionBar | 取消左、保存右，安全初始焦点 |

窗口案例只是减少控件数量以说明空间关系，不能另造一套按钮层级。未使用的元按钮/容量条等完整参考仍在index.html；不在窗口里强凑所有组件。
