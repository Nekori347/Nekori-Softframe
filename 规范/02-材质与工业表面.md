# 材质、色阶与工业表面

主依据：005材质分配、006分区、007内容锚定；003地形纠正优先于早期曲线示意。

## 主体与装饰分工

主体窗口/面板/按钮/卡片/输入/标签保持柔和圆角、留白与连续表面；工业层采用直角折线、刻度、角标、坐标、编号和技术注记，通常无明显投影。主体阴影柔和、强调前后关系；装饰反馈短促精确。拒绝主体全直角、霓虹泛光和满屏HUD。

系统材料负责空间深度，纸墨色负责视觉身份，工业纹理负责局部图形。它们叠加而非互斥。Mica是受桌面壁纸色调影响的不透明底层；Acrylic负责局部毛玻璃；Smoke式遮罩暗化背景并突出前景。纯HTML中的视觉模拟不能声称等同原生材料。

## 材料分配

| 角色 | 材料 | 色阶 | 装饰 |
| --- | --- | --- | --- |
| 外壳 | Mica或验证过的原生/后备背景 | 系统背景色调 | 无或极弱颗粒 |
| 标题栏 | 与外壳连续、受控透明 | 系统色＋纸墨轻染 | 身份线、少量微刻线 |
| 导航/侧栏 | 受控透明；必要局部应用内Acrylic | 导航色 | 边缘点阵/短刻线 |
| 主要内容 | 稳定纸墨底板 | Base | 局部低对比网格/地形 |
| 内容卡片 | 比底板更明确的半实色 | Layer1/Raised | 同类共享纹理 |
| 下沉属性分组 | 内部沉底表面 | Layer2/Recessed | 无或沿用父纹理 |
| 设置行 | 纸墨渐变表面 | Layer1–2 | 按下方分区语法 |
| 常规按钮/输入 | 较实功能面 | Control | 默认无纹理 |
| 主要操作 | 信号色表面 | Accent | 必要局部排线/端点 |
| 菜单/提示 | 局部Acrylic或高不透明度 | Overlay | 通常无纹理 |
| 独立详细浮层 | 圆角材料＋高层级阴影 | Elevated | 标题/边缘/空白局部 |
| 模态遮罩 | 半透明暗化 | Scrim | 无纹理 |
| 状态/进度/选中 | 原组件＋状态层 | Accent或语义状态 | 线、刻度、轮廓、端点 |

按语义与内容密度分配，不能只按“卡片”名字决定。正文、聊天、表格、编辑面稳定；导航/空白可通透。不能每嵌套一层就多一次模糊，优先色阶、边界和轻阴影；相邻Acrylic避免接缝。系统关闭透明度等情况下保留后备材料与清晰状态。

## 纸墨基线

以下八值是批次005采用的DSH社区参考基线，本轮核对与其设计文档一致；不是游戏官方Token，也不是所有项目永远固定的像素色。

| 语义 | Paper | Ink |
| --- | --- | --- |
| Base | `#e8e8e2` | `#101110` |
| Raised/Layer1 | `#f2f2ec` | `#181a18` |
| Recessed/Layer2 | `#dcddd6` | `#1e201d` |
| 结构重线 | `#b6b8b3` | `#4a4d49` |

视觉层级不是HEX越亮越高：下沉区由边界、嵌入关系等共同成立。颜色与材料不透明度分开管理。明暗主题分别配套，不能简单反相。历史`#3C3E41`仅某项目参考。

主题强调色集中可调，可考虑HSV编辑；服务身份、选中、焦点、状态和少量装饰，不把所有边框/按钮染色，更不写死终末地黄。危险色等语义状态独立于主题色。Logo保持官方形态和配色。前景文字、背景与材质合成一起考虑；装饰“可见但低干扰”和文字可读性不是同一种对比要求。

## 纹理投放

| 类型 | 合适位置 | 限制 |
| --- | --- | --- |
| 地形等高线 | 背景角、设置起始侧、资源卡片底部 | 不压长正文/输入 |
| 渐变网点 | 末端、控件背景、材料交接 | 不每个小图标都铺 |
| 斜向排线 | 起始锚区、结构边缘、未完成进度段 | 不等同风险警戒纹，不满幅铺所有卡片 |
| 警戒斜纹 | 风险、设备、高影响提示 | 不作普通导航/日常按钮默认 |
| 工程网格 | 大幅低信息区域 | 避开密集表格/聊天 |
| 细颗粒 | 基础纸墨或磨砂的微弱质感 | 不多层增强成脏污/摩尔纹 |
| 标尺刻度 | 参数、容量、进度 | 需数量/状态意义 |
| CAD线/L角标/编号 | 分组边缘、连接、重要技术标记 | 不替代主体圆角，不无意义连线或堆英文数字 |
| 渐变/光泽 | 表面明度差、克制边缘高光 | 不霓虹/RGB泛光 |

## IndustrialSettingRow：分区与前景

基础纸墨面带轻微横向材料渐变。A–D可以局部重叠，不硬切四个矩形；E是前景，不是第五栏。

| 区 | 组织 |
| --- | --- |
| A 最左窄锚区 | 细微渐变斜向平行排线，建立起始配重与方向，非警戒 |
| B 左侧地形窗口 | 真实母版裁切；疏松区偏标题侧，外围非对称渐密并淡出 |
| C 主体呼吸区 | 中段极弱纹理，沿阅读/操作路径留出安静过渡 |
| D 右侧参数背景 | 规则网点＋方向性透明度或点径渐变，低对比 |
| E 前景 | 标题、线轨、短胶囊柄、读数、按钮及状态最清楚 |

左锚定→中过渡→右操作。地形稀疏中心既不是整个条目50%，也不是文本精确中心。先确定稳定标题列/内边距，再定位共享起始侧锚区；允许文字附近经过少量低对比线条，不挖贴字空洞。

标题长短变化不让母版逐条重新居中、随机平移或重新生成。长文本可扩大低对比区或用有限预设裁切；纹理冲突先降低局部对比/调整裁切，不移动文字迎合纹理。稀疏区可一侧较快变密、另一侧缓慢过渡，不是同心环、均匀放射或左右对称。

“前导配重”“内容锚定的非对称纹理构图”是本规范的描述词，不冒充官方组件术语。渐变点阵在这里指规则低对比半调式网点场，非LED点阵或随机dots。

## 地形真实性与复用

地形由真实DEM或虚拟连续高度场的等值线构成，有弯折、闭合、山脊/谷地、自然间距变化。缓坡疏、陡坡密。不能用同趋势平行贝塞尔波纹＋文字下遮罩冒充地形。

分别控制几何疏密（高度场/等高距）与视觉显著度（位置/裁切/透明度）。设置行B区向外围可更密但更淡；不把此局部构图规则强加所有背景地形。

主题维护少数固定母版，种子与输出生成后固定。可按常规条目、大面积、密集局部准备；历史Terrain A山脊/B闭合高地/C陡坡/D可选缓坡是建议角色，非必须创建四文件。

- 同类复用：同母版/比例/起始位置，允许少量预设裁切变体。
- 区域连续：父面板共享地形坐标，子区域显示对应裁切，适合连续设置/资源列表；独立间隔卡片无需强制如此。
- 小按钮/标签通常无完整地形，必要时只低对比片段；中型固定局部裁切；大型展示更多闭合起伏并保留中段安静区。
- 保持长宽比和稳定视觉尺度，不把1024方图拉成300×40，也不为每尺寸相同线数反复缩放。
- 不要求鼠标跟随/持续动态地形。位置示意中的简化线条不能作为正式母版。

## 装饰密度

D0：基础材料/文字/必要边界，适合输入/正文/紧凑列表。D1：小片低对比纹理与结构线，适合设置/普通卡片。D2：克制的纹理组合、角标与主题线，限重要区域。D3：较广地形/网格/水印/技术符号，限欢迎、加载、展示。

日常D0/D1，少量D2，D3非默认。不是每条都必须全套纹理。

主题层一次确定：系统材料→纸墨色阶→内容层级→固定纹理投放→状态强调。`texture`管素材，`texturePlacement`管区域、裁切、尺度、透明度、面积，避免各按钮随意铺满或拉伸。试验范围见[参数](04-资源与参数.md)。


完整窗口内的分配与交互关系见[窗口表现与表面层级](08-窗口与层级.md)和[独立HTML参考](../案例/窗口与层级.html)。内部控件与整个窗口的材料层级应一起检查。
